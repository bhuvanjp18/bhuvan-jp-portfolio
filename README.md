# Bhuvan JP — Product Portfolio

A static portfolio for product management, product operations, AI product, and product analytics roles. Built with HTML, CSS, and vanilla JavaScript; no build step is required.

## Files

- index.html — portfolio content and structure
- style.css and aesthetic.css — layout and visual styling
- script.js — case-study dialogs
- .nojekyll — tells GitHub Pages to serve files without Jekyll processing

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub Pages will publish the site at:

https://bhuvanjp18.github.io/bhuvan-jp-portfolio/

## Case-study boundaries

The provider calendar case study reflects the experience and outcomes described in the portfolio. The Zapier/n8n lead-routing project is presented without unprovided routing details or impact figures. The customer-feedback synthesis project is clearly labeled as a self-directed concept.
